# Shanmugapriyan Portfolio

A 3‑D HUD style personal portfolio built with **HTML**, **CSS**, **Three.js**, and **Chart.js**.

## Features
- Interactive 3‑D HUD rendered with Three.js
- Dynamic radar chart showcasing skills
- Theme switcher (Cyber, Blue, Purple, Light)
- Responsive design with glass‑morphism effects

## Project Structure
```
prot.html          # Main HTML entry point (rename to index.html for GitHub Pages)
styles.css         # All extracted CSS styles
script.js          # All extracted JavaScript logic
README.md          # This file
```

## Local Development
1. Open `prot.html` (or `index.html` after renaming) in a browser.
2. No server is required – all assets are loaded via CDN.
3. Edit `styles.css` or `script.js` and refresh the page.

## Deploy to GitHub Pages
1. Create a GitHub repository and push the three files.
2. Rename `prot.html` → `index.html` (GitHub Pages serves `index.html` by default).
3. Enable **Pages** in the repo settings (branch: `main`, folder: `/`).
4. Your site will be available at `https://<username>.github.io/<repo>/`.
